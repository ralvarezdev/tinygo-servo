# tinygo-servo

Servo wrapper for TinyGo projects, built on [`tinygo-pwm`](https://github.com/ralvarezdev/tinygo-pwm) and [`tinygo-errors`](https://github.com/ralvarezdev/tinygo-errors).

**Note:** This repository is archived and read-only.

## Features

- **`DefaultHandler`** — `GetAngle`, `SetAngle`, `IsAngleCentered`, `SetAngleToCenter`, `SetAngleRelativeToCenter`, `SetAngleToRight` and `SetAngleToLeft`.
- **`Direction`** — Direction enum with `InvertedDirection`.
